# FrameBaker Skills Archive

This directory archives the plugin-packaging skills used with FrameBaker's
independent media plugin system. The archived files are copied from:

```text
F:\TestProject\aigc_bench\skill
```

## Archived Skills

- `image_api_plugin_packager/` — package and validate `.iap` image API plugins.
- `video_api_plugin_packager/` — package and validate `.vap` video API plugins.
- `audio_api_plugin_packager/` — package and validate `.aap` audio API plugins.
