## 本次最小交付

已有 PNG/ZIP 导入入口现在可为每个动作保存：

1. `hit` 受击参考 anchor；导出为每帧 `anchors[]`。
2. 平A/特殊攻击的 `muzzle` anchor（带可选方向）。
3. 平A的 `weapon.fire` 或特殊攻击的 `effect.trigger` 发射时刻，均强制为 `presentationOnly: true`。
4. API 的 `frameAnchors` 逐帧覆盖，供移动枪口/受击点使用；UI 的基础表单将固定 anchor 复制到每帧，允许未完成工程保留为空。

导出器会拒绝超出同画布的坐标、同帧重复 anchor、超过帧数的逐帧覆盖、`combat.hitbox.*`、非表现标记以及不在 `[0, durationMs)` 的时刻。它不接受任何目标、伤害、命中框或机制字段。

- `assets/attack/54.png` 显示现有红色枪口闪光；制作采样从该帧量取 `muzzle`，而不是另造一份无人机。
- `assets/hit_received/*.png` 是受击动作，应量取 `hit` 参考点。
- FrameBaker 已有确定性攻击特效笔刷 `spark`，可在源工程做金属命中火花；它不是新的战斗 wire，也不等于客户端已经能加载独立特效资源。
